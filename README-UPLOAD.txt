S&K WOOD FLOOR SPECIALISTS, IMPROVED WEBSITE

UPLOAD
1. Download and keep a backup of the current GitHub repository.
2. Extract this ZIP on your computer.
3. Open the extracted SK_Wood_Floors_Improved folder.
4. Copy every file and folder inside it into the root of the GitHub repository.
5. Replace the old HTML files and upload the css, js and images folders completely.
6. Commit and push the changes. Vercel should deploy automatically.
7. Test every menu link, the WhatsApp buttons and one quote-form submission.

IMPORTANT FORM STEP
FormSubmit may send a one-time activation email to info@skwoodfloorspecialists.co.uk. Open that email and confirm the form before expecting enquiries to arrive.

KEY CHANGES
- Floor sanding is the primary service across the site.
- Restoration is second priority.
- Installation covers engineered wood, solid wood, laminate, parquet and herringbone.
- All included images are optimised WebP files.
- Project gallery data is held in js/projects-data.js.
- Forms route to the business email and then to thank-you.html.
- Added privacy notice, sitemap, robots.txt, 404 page and structured data.
